# PointGPS

### ポイント(GPS)の作成・編集

- Excel(.xlsx) の GPS ポイントデータを読み込み、国土地理院地図の上で**ポイントの追加・移動・削除**と、
  ポイントID・名称・備考の編集を行い、Excel(.xlsx) として出力する。
- 標高は国土地理院の標高API から自動で取得する。

ここで作成したポイントは、GeoReferencer でハイキングマップ画像を地図に重ね合わせる際の**基準点（制御点）**として使う。

## 実装機能

画面は全画面の地図と、右上の操作パネル「ポイント(GPS)編集」で構成する（モード切り替えは無い）。

| 機能 | 主な操作 |
|------|---------|
| ポイント読み込み(Excel) | Excel を読み込み、全ポイントを地図上に緑の円マーカーで表示。ポイント数を表示 |
| ポイントの選択 | マーカーをクリックすると選択（ライムグリーン）し、ID・名称・緯度・経度・DMS・標高・備考を表示 |
| 追加 | 地図上をクリックした位置に仮ID（`仮01`, `仮02` …）で追加。既存ポイントから 10px 以内には追加できない |
| 移動 | 選択中のポイントをドラッグして移動。ドラッグ中は座標をリアルタイム表示し、移動後に標高を再取得 |
| 削除 | 確認のうえ、選択中のポイントを削除 |
| 属性編集 | ポイントID（最大5文字）・名称（最大20文字）・備考（最大50文字）を編集 |
| ポイント出力(Excel) | 保存先を選んで全ポイントを Excel で出力。標高未取得のポイントがあれば、取得してから出力するかを確認 |

`Esc` キーで追加・移動の操作を取り消す。

ポイントID は入力確定時に次のように自動で整形する（漢字・かなを含む場合は全角英数字の半角化のみ）。

- 全角英数字・全角ハイフンを半角に変換し、英字は大文字にする
- 空白を削除する
- 末尾が 1 桁の数字なら 0 を補う（例: `ab3` → `AB03`）
- 3 文字以内の「英字＋数字」なら間にハイフンを入れる（例: `a1` → `A-01`、`B12` → `B-12`）

標高は、値が空または 0 のポイントについて、選択時・追加時に国土地理院の標高API から取得する（小数点以下 1 桁）。
出力時の一括取得では、API への連続アクセスを避けるため 0.5 秒間隔で取得する。

## 役割分担

| リポジトリ | 役割 |
|---|---|
| **PointGPS** | 基準となるポイントの GPS 値を作成・編集し、Excel を出力する |
| PointMarker | ハイキングマップ画像上のポイント・ルート・スポットをマーキングし、画像内座標を出力する |
| GeoReferencer | PointGPS の Excel を制御点として画像をジオリファレンスし、地域別の GeoJSON を出力する |
| MapEditor | 地点・ルート・スポット・エリアの編集、通行止め地点の登録。作業用 GeoJSON を出力する |

PointGPS の出力 Excel は GeoReferencer・MapEditor の GPS ポイント入力と同じ列構成である。

## 入出力ファイル

| 種類 | 入力 | 出力ファイル名 |
|------|------|---------------|
| GPS ポイント | Excel(.xlsx) の先頭シート。必須列: ポイントID・名称・緯度・経度、任意列: 標高・備考（ヘッダー行を含め最大 1000 行） | `ポイントGPS-{YYYYMMDD}.xlsx`（シート名 `ポイントGPS`） |

- 1 行目はヘッダー行で、列名は完全一致で判定する（列の順序は問わない）
- 緯度・経度は 10 進数のほか、度分秒（例: `34°51'13.2"`、`34度51分13.2秒`）も読み込める
- 必須列の値が空の行、緯度・経度が数値にならない行は読み飛ばす
- 出力では緯度・経度を小数点以下 5 桁に丸め、標高は数値として書き込む

## 開発・動作確認

ES6 モジュール構成のため、ローカルで動かすときは CORS 制限を回避するローカルサーバーが必要。

```bash
python -m http.server 8000
# または
npx serve .
# ブラウザで http://localhost:8000 を開く
```

ビルドプロセスは無い。外部ライブラリは CDN から読み込む。

- Leaflet 1.9.4（地図表示）
- SheetJS (xlsx) 0.18.5（Excel 読み込み・出力）

外部サービスとして、国土地理院の地理院タイル（標準地図）と標高API を使う。
地図の初期表示は箕面大滝（緯度 34.853667, 経度 135.472041）、ズーム 15。

## 制約事項

- Excel の読み込みは置き換え式で、読み込むたびに既存のポイントはすべて破棄される
- ポイントID の重複チェックは行わない
- 元に戻す（Undo）機能は無い。編集内容は出力しない限り保存されない
- GeoJSON の入出力には対応しない
